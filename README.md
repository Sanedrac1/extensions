# Sanedrac1 Extensions

## Usage
**If you are new to repository/extensions, please read the [Sanedrac1 Getting Started guide](https://Sanedrac1.github.io/docs/guides/getting-started#adding-the-extension-repo) first.**

* You can add our repo by visiting the [Sanedrac1 Website](https://Sanedrac1.github.io/add-repo)
* Otherwise, copy & paste the following URL: https://raw.githubusercontent.com/Sanedrac1/extensions/repo/index.min.json
